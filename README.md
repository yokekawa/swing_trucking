# 野球スイング軌道 可視化アプリ

動画をアップロードすると、MediaPipe Pose で両手首の軌道を抽出し、2D / 3D で
スイングの軌跡を可視化する Streamlit アプリです。

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Python 3.10 以降を想定しています。

## 起動

```bash
streamlit run app.py
```

ブラウザが開いたら、サイドバーからスイング動画 (`mp4` / `mov` / `m4v` / `avi`) を
アップロードしてください。解析が終わると以下 3 タブが表示されます。

- **2D 軌道**: スイング中央フレームに軌道を重ねた 2D プロット (時間で色がグラデーション)
- **3D 軌道**: 腰中心を原点とした相対 3D 軌道 (plotly, 回転/ズーム可)
- **メトリクス**: 最大スイング速度、軌道長、スイング面の傾き、速度プロファイル

## 撮影ガイド

- バッター全身が横から 1 人だけ入る構図
- 60fps 以上推奨 (速度推定の精度が向上)
- 手元が明るく写っていること (影で手首を見失うと軌道が欠ける)

## 構成

| ファイル | 役割 |
| --- | --- |
| `app.py` | Streamlit UI |
| `swing_analyzer.py` | 動画 → 両手首ランドマーク時系列の抽出 + スイング区間検出 |
| `visualizer.py` | 2D / 3D / 速度プロファイルのプロット生成 |
| `requirements.txt` | 依存関係 |

## 注意

- MediaPipe の world landmarks はスケールが近似値であり、3D 軌道は「相対的な軌道」
  として参照してください。
- バット自体は検出せず、両手首の中点で軌道を近似しています。
